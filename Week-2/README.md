# Skill Nexis – Week 2 Java OOP Assignments

## Assignments
- `Student.java` – Student class, constructor, and display method.
- `VehicleDemo.java` – Inheritance, method overriding, and runtime polymorphism.

## Mini-project: Library Management System
Located in `LibraryManagement/`.

- `Book.java` – Book details and availability.
- `User.java` – Abstract user class.
- `StudentUser.java` – Student user implementation.
- `Library.java` – Add, display, borrow, and return operations.
- `LibraryManagementApp.java` – Console menu and application entry point.

## Run
Open the `Week-2` folder in IntelliJ IDEA and run `Student.java`, `VehicleDemo.java`, or `LibraryManagement/LibraryManagementApp.java`.

This is a basic console demonstration. It tracks book availability but does not save data after the program exits or record which individual user borrowed a book.
