# Week 1 – Java Fundamentals

This folder contains solutions for the Week 1 Java assignments.

## Files
- `BasicCalculator.java` – Addition, subtraction, multiplication, and division.
- `GradeEvaluation.java` – Prints a grade based on marks.
- `BankManagement.java` – Menu-driven console banking app with deposit, withdrawal, and balance check.

## Requirements
- Java JDK installed
- Terminal, VS Code, IntelliJ IDEA, or Eclipse

## Compile and run
Open a terminal in this folder.

### Basic Calculator
```bash
javac BasicCalculator.java
java BasicCalculator
```

### Grade Evaluation
```bash
javac GradeEvaluation.java
java GradeEvaluation
```

### Bank Management
```bash
javac BankManagement.java
java BankManagement
```

## Notes
The grade thresholds used in `GradeEvaluation.java` are example values because the assignment PDF does not specify a grading scale:
- 90–100: A
- 75–89: B
- 50–74: C
- Below 50: Fail

The bank application starts with a demonstration balance of 1000.0. It is a basic console program and does not persist account data.
